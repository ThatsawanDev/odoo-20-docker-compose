# JSN Service ERP ภาษาไทย

โมดูลนี้ต่อยอด `thai_sales_stock_easy` และ `machine_service_management` ให้ตรงกับงานบริการเครื่องพิมพ์วันที่ตาม scope โครงการ ลูกค้า เครื่องตาม S/N รายงานบริการ 5 ประเภท งานซ่อมภายใน อะไหล่ คู่มือ รุ่นเครื่อง และสินทรัพย์ถาวรอยู่ในเมนู Service ERP หน้าใบเสนอราคาใช้ `thai_sales_stock_easy` โดยตรง

## ฐานข้อมูลตัวอย่าง

`thai_scope_demo_20261116` ติดตั้ง `spiffy_theme_backend`, `thai_sales_stock_easy` (รวม `dynamic_accounts_report` และ `base_accounting_kit`), `machine_service_management` และ `jsn_service_scope` พร้อมลูกค้า เครื่อง EMICO E860TP/E850T อะไหล่ ใบงาน ใบเสนอราคา และสินทรัพย์ตัวอย่าง ข้อมูลที่สร้างโดยโมดูลนี้มีคำว่า “ตัวอย่าง” หรือ S/N ลงท้าย `-DEMO` ภาพเครื่องในข้อมูลตัวอย่างเป็นภาพสร้างขึ้นเพื่อประกอบการสาธิต

## ขั้นตอนใช้งาน

1. เพิ่มลูกค้าและผู้ติดต่อ แล้วสร้างใบเสนอราคาขายเครื่องและบริการในชุดขาย
2. ยืนยันใบขายและใบส่งสินค้า จากใบขายกด “ลงทะเบียนเครื่อง” เลือกสินค้าที่ขาย รุ่น และ S/N ที่ส่งจริง ระบบเชื่อมลูกค้า ใบขาย ใบส่ง และทะเบียนเครื่อง
3. จากทะเบียนเครื่องเปิดงานบริการ เลือกประเภท มอบหมายช่าง และระบุว่าคิดค่าบริการ อยู่ในประกัน หรืออยู่ในสัญญา หน้ารายงานบริการเปิดด้วย Kanban ที่แสดงรูปเครื่องและสถานะงาน
4. บันทึกอาการ การวิเคราะห์ การซ่อม อะไหล่ที่เปลี่ยน และผลทดสอบ
5. ถ้าอะไหล่ไม่พอ กด “สั่งซื้ออะไหล่ที่ขาด” เลือกผู้ขาย ระบบสร้างใบสั่งซื้อเฉพาะจำนวนที่ขาด ยืนยันใบสั่งซื้อและรับสินค้าเข้าคลัง
6. กด “สร้างใบเบิกอะไหล่” ระบบตรวจยอดคงเหลือ สร้างและจองรายการเบิก เชื่อมรายการเบิกกับบรรทัดอะไหล่ ยืนยันใบเบิกให้เสร็จก่อนปิดงาน
7. งานที่คิดค่าบริการกด “สร้างใบเสนอราคา” ในใบงานเพื่อส่งค่าแรงและอะไหล่ไปยังชุดขาย งานในประกันต้องเปลี่ยนนโยบายคิดค่าบริการก่อนหากมีรายการเรียกเก็บเงินจริง
8. ปิดใบงานและพิมพ์ “รายงานบริการ (JSN)” เป็น PDF
9. บันทึกสินทรัพย์ในทะเบียน `account.asset.asset` ของ `base_accounting_kit` และเชื่อมกับทะเบียนเครื่องเมื่อเกี่ยวข้อง

ใบเบิกอะไหล่จะยังไม่ตัดสต็อกจนกว่าผู้ใช้ยืนยันการโอนตามขั้นตอนคลังของ Odoo สินทรัพย์ใช้ระบบบัญชีของ `base_accounting_kit` ซึ่งมีตารางค่าเสื่อมและรายการบัญชี การติดตั้งอะไหล่ตาม S/N ใช้ความสามารถเดิมของโมดูลฐานและเกิดหลังยืนยันใบเบิกแล้ว PM อัตโนมัติยังถูกซ่อนตาม scope

บทบาทที่เตรียมไว้: ผู้ดูแลระบบบริการ, ฝ่ายบริการ, ช่างเทคนิค, คลังอะไหล่ กำหนดสิทธิ์ให้ผู้ใช้จากหน้าการตั้งค่า
