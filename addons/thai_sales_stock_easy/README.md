# ระบบขายและสต็อก ภาษาไทย

โมดูลศูนย์รวมงานประจำวันสำหรับผู้ใช้ที่ต้องการเมนูภาษาไทย ตัวอักษรใหญ่ และขั้นตอนตรงไปตรงมา

## เมนูหลัก

- ภาพรวม พร้อมตัวเลขงานค้างและทางลัด
- งานขาย: ใบเสนอราคา รายการขาย ลูกค้า
- งานซื้อ: ใบขอซื้อ/ใบสั่งซื้อ รอรับสินค้า ผู้ขาย
- คลังสินค้า: รอส่ง รับเข้า เบิกออกแบบง่าย ยอดคงเหลือ
- การเงินและภาษี: รอรับเงิน ใบกำกับภาษีขาย และบิลเจ้าหนี้

## การเบิกสินค้าแบบง่าย

ระบบเลือกคลังหลักของบริษัทให้อัตโนมัติ ผู้ใช้เลือกสินค้า จำนวน และผู้รับเท่านั้น
สินค้าที่ควบคุมล็อตหรือเลขซีเรียลจะเปิดใบเบิกให้ระบุล็อตก่อนยืนยันตามข้อกำหนดของ Odoo
