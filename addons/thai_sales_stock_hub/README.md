# ศูนย์ออเดอร์ทุกช่องทาง

โมดูลต่อยอด `thai_sales_stock_easy` สำหรับหน้าภาพรวมและศูนย์ออเดอร์บนโมเดลมาตรฐานของ Odoo 19

- เมนู **ศูนย์ออเดอร์ → ออเดอร์ทุกช่องทาง** รวมรายการขายทุกช่องทางและทุกสถานะงานในตารางเดียว
- หน้าศูนย์ออเดอร์ใช้ List/Search/Form มาตรฐานของ Odoo ไม่มีแถบเมนูหรือแผงรายละเอียดที่สร้างซ้ำ
- ค้นหาเลขออเดอร์ Odoo เลขอ้างอิงช่องทาง ลูกค้า และช่องทางได้ด้วยช่องค้นหามาตรฐาน พร้อมตัวกรองและจัดกลุ่ม
- ตารางแสดงรูปสินค้ารายการแรก ช่องทางขาย และเครื่องหมายข้อมูลตัวอย่าง กดแถวเพื่อเปิดใบขาย Odoo โดยตรง
- เมนู **ศูนย์ออเดอร์ → ตั้งค่า → ช่องทางการขาย** ให้ผู้ดูแลแก้ชื่อ เปิด/ปิด และเปลี่ยนไอคอนได้ มีไอคอนเริ่มต้นสำหรับขายตรง หน้าร้าน เว็บไซต์ Shopee Lazada TikTok Shop และช่องทางอื่น
- **ศูนย์ออเดอร์** เป็นแอปหลักแยกจากระบบขายและสต็อก เปิดหน้าภาพรวมการดำเนินงานวันนี้เป็นหน้าแรก
- แดชบอร์ดใช้ยอดจริงจาก `sale.order`, `stock.picking`, `purchase.order`, `product.product` และ `mrp.production` เมื่อมีโมดูลผลิต
- ระบุช่องทางขายและเลขออเดอร์จากระบบต้นทางบนใบขาย ค้นหา กรอง และจัดกลุ่มได้
- ทางลัดไป Marketplace, แพ็กและจัดส่ง, ตรวจสต็อก, ออกบิลและรับเงิน โดยใช้โมเดลมาตรฐานเดิม
- รองรับหลายบริษัทผ่านสิทธิ์และ company context ของ Odoo
- แดชบอร์ดเดิมแสดงส่วนออเดอร์ทุกช่องทางพร้อมจำนวนร้านค้าที่ตั้งค่าในตัวเชื่อม Marketplace
- เมนู **ศูนย์ออเดอร์ → ตั้งค่า** รวมช่องทางการขาย บัญชี และร้านค้าของตัวเชื่อมแต่ละราย

โมดูลนี้ใช้ `sale_shopee`, `sale_lazada` และ `smart_sale_tiktok` เป็นตัวเชื่อม Marketplace โดยตรง เมนู **ตั้งค่า** เปิดบัญชีและร้านค้าของแต่ละโมดูลเพื่อกำหนดการเชื่อมต่อและซิงค์ ออเดอร์ที่ตัวเชื่อมนำเข้าจะได้ช่องทางขายและเลขอ้างอิงในศูนย์ออเดอร์โดยอัตโนมัติ ต้องเพิ่มบัญชีและร้านค้าพร้อมสิทธิ์ API ในโมดูลตัวเชื่อมก่อนจึงจะซิงค์ได้

ใช้เมนู Import ของรายการ Odoo ได้โดยตรง และใช้คำสั่งซิงค์ของแต่ละโมดูลหลังตั้งค่าบัญชี ร้านค้า และสิทธิ์ API แล้ว

ไฟล์ `scripts/seed_order_center_demo.py` ใช้เพิ่มลูกค้าตัวอย่าง 3 รายและใบเสนอราคาตัวอย่าง 6 รายในฐานข้อมูลที่เลือก ข้อมูลตัวอย่างติดป้ายในหน้าศูนย์ออเดอร์และจะไม่ถูกสร้างอัตโนมัติเมื่อติดตั้งโมดูลในฐานข้อมูลอื่น สคริปต์รันซ้ำได้โดยไม่สร้างออเดอร์ซ้ำ

ยอดแดชบอร์ดนับเฉพาะบริษัทที่ผู้ใช้เลือกในตัวเลือกบริษัทของ Odoo และออเดอร์ที่เข้าถึงได้ตามสิทธิ์ผู้ใช้ ไม่ใส่ตัวเลขตัวอย่างจากภาพ mockup
